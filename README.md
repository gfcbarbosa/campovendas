# CampoVendas · GFB AGRO

App de cotações (padrão Calculadora GFB AGRO), vendas, entregas e metas.

Novidades: **Barter** em cada cotação (sacas de soja/milho com Funrural e Senar) e **Receitas agronômicas** (Mais → Receitas agronômicas), com plano por operação, conferência com a cotação e PDF da receita. **Análise de solo** (Início ou Mais; software Fertilidade do Solo Cerrado). **Calculadora financeira** (Início ou Mais): juros compostos para levar um valor ao futuro ou trazer para hoje.

**Abrir o app:** https://gfcbarbosa.github.io/campovendas/

- Instale no iPhone: abra o endereço no Safari → Compartilhar → "Adicionar à Tela de Início".
- Os dados (clientes, cotações, vendas) ficam salvos **somente no aparelho**, não neste repositório.
- Faça backup em Mais → Backup e Excel.
